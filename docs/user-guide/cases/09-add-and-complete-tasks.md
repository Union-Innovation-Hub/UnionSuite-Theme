**Add a task**

1. On the **Overview**, find *Tasks* and press **Add task**.
2. Type what needs doing.
3. Choose a **Due Date** if it has one.
4. Press **Save task**, or press `Enter`.

The box stays open so you can add the next task straight away. Press **Add task** again to close it.

**Complete a task**

- Tick the box beside the task.
- Completed tasks are hidden. Press **Show completed tasks** to see them.

> **Tip:** A note with **Follow up** ticked is also a task. See [Add a note](#add-a-note).
