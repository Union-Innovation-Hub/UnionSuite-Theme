1. Open the **Activity** tab.
2. Choose **Changes** at the top.
3. Each card is one save, such as *Case updated*, *Party added* or *Staff removed*, with who made it and when.
4. Select a card to see what changed, as old value → new value.

> **Tip:** Press **Details view** for the full history log, which you can export.
