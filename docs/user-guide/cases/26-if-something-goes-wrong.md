**A save failed**

A message says it was not saved. What you typed is kept. Try again.

**I lost what I was writing**

- Pressing the add button again (such as **Add note**) only puts your writing away. Press it again to get it back.
- **Cancel** or `Esc` throws it away for good.

**A list looks out of date**

Reload the page.

**It keeps happening**

Tell your system administrator. Say which case, what you pressed and what the message said.
