**The banner** at the top shows the case number, title, status and the member. See [Read the banner](#read-the-banner).

**The tabs** run down the right side:

| Tab | What you find there |
| --- | --- |
| **Overview** | The member, open tasks, upcoming meetings, the newest files, the case team and the last 30 days of activity. Start here. |
| **Details** | The case's own details, and its resolution. |
| **Activity** | The whole history of the case: notes, emails, meetings, files and changes. |
| **Parties** | Everyone the case is about: members and employers. |
| **Attachments** | Every file on the case. |

> **Tip:** On a small screen the member comes first, then the tasks and activity, then the files and the case team.
