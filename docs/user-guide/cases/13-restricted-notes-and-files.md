**Restricted notes**

1. A restricted note shows a notice instead of its text.
2. Press **Show note**.
3. If you are allowed to see it, the note opens.

**Restricted files**

1. A restricted file shows a padlock and an **Unlock** button instead of View and Download.
2. Press **Unlock**.
3. If you are allowed, the padlock opens and **View**, **Download** and **Edit** appear.
4. If not, the button shakes and the reason shows beside it for a few seconds.
