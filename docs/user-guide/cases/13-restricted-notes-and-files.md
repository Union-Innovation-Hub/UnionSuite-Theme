Being able to open a case doesn't mean you can see everything in it. Each note has its own **Access**, chosen when it's added, with the same choices as a case:

| Access | Who can see the note |
| --- | --- |
| **Open** | Everyone who can open the case. |
| **Team** | Staff with the *Case Team* role. |
| **Individual** | Only staff on the case team. |

So a note set to **Individual** stays hidden from staff who can open the case but aren't on its team.

**Restricted notes**

1. A restricted note shows a notice instead of its text.
2. Press **Show note**.
3. If you are allowed to see it, the note opens.

**Restricted files**

1. A restricted file shows a padlock and an **Unlock** button instead of View and Download.
2. Press **Unlock**.
3. If you are allowed, the padlock opens and **View**, **Download** and **Edit** appear.
4. If not, the button shakes and the reason shows beside it for a few seconds.

> **Tip:** To keep a note to the case team, set its Access to **Individual** when you add it.
