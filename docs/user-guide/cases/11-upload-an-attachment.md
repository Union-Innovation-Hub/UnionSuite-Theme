**Upload**

1. Press **Upload**. You find it on the Overview's *Attachments*, the **Attachments** tab and the **Activity** tab.
2. Drop your files into the box, or select it to choose them.
3. Remove any file you added by mistake with the **×** beside it.
4. Add **Tags** to say what the files are.
5. Press **Upload**.

**Find and open files**

- The Overview shows the newest three. Press **View all attachments** to see them all.
- Use **View** to open a file and **Download** to save a copy.
- Use **Edit name and tags** to rename a file or change its tags.
