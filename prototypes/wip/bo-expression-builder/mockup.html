What changes

  1. Formula line. The whole expression in one readable line at the top, with the property's name. Click a term to find its row; hover a row to find its term. Stock iMIS shows raw SQL only, at the very bottom.
  2. Flat rows. A run of + is one term per row with the operator in front. The repeated "Calculation / No function" rows are gone. If / then / else keeps its own block because it is real nesting.
  3. Searchable properties. Click a property and type, for example name city. The table name is muted and the column is bold.
  4. Quieter rows. The data type is a badge, not a disabled dropdown. "Add function" stays faint until a function is set. Replace reads "find … with …" on one line and says when a box holds spaces or nothing.

The controls work in this mock-up: change a property, an operator or a function and the formula line follows. In iMIS each change is still a server round trip.

What iMIS draws today

  1. Each + nests the rest of the expression in another box: six terms, six levels.
  2. 54 dropdowns on a panel about 1,300px tall. Scroll the panel: the popup shows about a third of it.
  3. Every level repeats a "Calculation / No function" row.
  4. Each property dropdown is a plain list of 127 entries, and each row carries a disabled data type dropdown.
  5. The Replace "find" box looks empty but holds a space.
  6. The only overview is the raw SQL at the very bottom.
